Infrastructure lead on a real-time, hands-free cooking assistant built for the Gemini Live Agent Challenge. Provisioned GCP infrastructure including Cloud Run, Firestore, IAM, and Secret Manager. Set up CI/CD via Cloud Build and managed submission assets.
- **Tech:** GCP (Cloud Run, Firestore, Secret Manager, Cloud Build), FastAPI, React, Vite, Gemini Live API
- **Highlights:** End-to-end GCP provisioning and IAM configuration; automated CI/CD pipeline; real-time voice-driven interaction via Gemini Live API

### 🌐 [KreptKon — Containerised Flask Microservice on AWS](https://github.com/han-re/kreptkontainer)
Built and deployed a Flask REST API as a containerised microservice on AWS EKS. Integrated RDS for persistent storage, ECR for image management, and CloudWatch for monitoring. Authored YAML-based infrastructure configurations with auto-scaling.
- **Tech:** Python, Flask, Docker, Kubernetes, AWS (EKS, RDS, ECR, CloudWatch)
- **Highlights:** Production-style microservice architecture on EKS; YAML IaC with auto-scaling; full observability via CloudWatch

### 🚀 [RelicBound — Full-Stack Adventure Game](https://github.com/han-re/RelicBound0)
Led a 4-person team to build a choice-based adventure game with persistent user sessions, authentication, and real-time player analytics.
- **Tech:** JavaScript, SQL, HTML, CSS, PHP
- **Highlights:** Dynamic decision system; SQL-based progress tracking; real-time success metrics; team leadership

### ⚙️ [Exhibition Management System](https://github.com/han-re/Museum_Manager)

- **Tech:** Java
